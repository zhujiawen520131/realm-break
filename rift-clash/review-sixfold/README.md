# 霹雳一闪·六连：独立像素演出审稿

本目录仅供动作和视觉审核，没有导入原游戏引擎，也不实现伤害、锁敌或无敌规则。六段折线对应上传动画的可见路径，不能推断为六次伤害。

将实际 `assets/*.png` 与符合 `manifest-contract.md` 的 `manifest.json` 放在同目录，通过静态 HTTP 服务打开 `index.html`。缺少任何实际引用素材时页面显示缺项并禁止播放，不渲染替代人物。父级发布路径为 `review-sixfold/`，返回链接指向 `../review-pixel/`。

演出时间轴长24.27857秒，保留完整施术者独有镜头；精确 sourceStart/sourceEnd 与剪辑说明位于 `timeline.json`，页面来源折叠区可见。六折源范围32.52577–33.61590秒，屋顶终结保留至35.00619秒。移除网页停留和敌方上下文，像素人物无鞘、场景坐标、镜头与音效均为明确改编。

支持播放、暂停、拖动、单帧步进、重播、速度、固定左右镜像、弱化动态、可关闭合成音效、逐素材帧查看、整体与阶段备注、本地保存和复制反馈。审核结论默认待审核。存储绑定清单与时间轴的内容指纹；无法持久存储的浏览器仍可播放和复制。

运行 `npm test` 检查导演时间、镜像、冻结、事件、实际帧引用、绘制参数、音频取消及审核隔离。测试采用绘图命令和音频节点替身，不能替代真实 PNG 的浏览器视觉审核。

浏览器审核接口为 `window.SixfoldPreview`：`inspect()`、`timeline()`、`seek(ms)`、`play()`、`pause()`、`assets()`、`showFrame(clip,index)`。seek 会暂停并取消音频，不回放已跳过的声音事件。
