# 裂界 R6 像素美术审核样稿

本目录是新像素风格的**待审样稿**，不继承 R5 或旧手绘设计的批准，也不代表六位角色的全部动作、技能或 440 帧已经重制。未修改游戏代码。

## 审核内容

- `manifest.json`：10 个条目，包括六人设计、克劳德挥砍、炭治郎水流斩、善逸雷光拔刀和战场。全部状态为 `pending`。相对路径与 SHA-256 覆盖每张主图和 24 张预览帧。
- `six-design-sheet.png` 及 `designs/`：六人统一风格设计原稿和各角色单图。图像带半透明背景光晕，仅供画风审核，不是可直接用于游戏的干净透明角色精灵。
- `cloud-slash-clean-sheet.png`、`zenitsu-lightning-clean-sheet.png`：八姿态序列。炭治郎最终总览 `tanjiro-water-review-sheet.png` 由实际 8 张审稿帧拼合；其中第 3 帧来自单独重绘的 `tanjiro-pose3-source.png`，其余帧来自 `tanjiro-water-final-sheet.png`。
- 三套序列均为**角色与效果合成的动作样稿**，不是独立 FX 层。`frames/` 中 24 张图片及每帧时长供审核播放；所标时长是示意节奏，不是游戏帧表或碰撞设定。
- `arena-raw.png` 为场景生成原图，`arena-1200x640.png` 按近似原始宽高比使用最近邻调整。平面地面交界约在 y=510，未画可行走的前景高台；实际平台和碰撞由游戏另行实现。

## 图像、像素网格与切分

原始生成图、各轮修订和每次完整提示词均保留；文字和参考路径见 `prompts.json`。图像生成时要求有手工组织的硬边像素团、每种材质约 3–5 级明暗、角色原生尺寸约 100–140 像素，但生成结果是高分辨率审稿图，并未证明遵守单一规则像素网格或固定色数，不可直接当作已完成的原生分辨率资产。

六人原稿为 1536×1024、3 列×2 行，各角色的实际裁切范围记录在其 manifest 条目的 `extraction.rect`（`x, y, width, height`）。天命人左侧长棍跨过名义等分边界，裁切有意从 x=960 开始，劳拉裁切在 x=960 结束。

三组动作生成底稿为 1774×887，4 列×2 行，按从左至右、从上至下阅读；并非每个分格都正好等宽。为避免裁断长剑，实际分界选在相邻图像的透明间隙。每帧的 `extraction.rect`、`padding`、源图和 SHA-256 都列在 manifest 中；`visibleEdgePixelsAlphaOver64` 是源裁切边上 alpha 大于 64 的像素计数，24 帧的四边计数均为 0。该检查不能替代合成显示、锚点及连续性审核。

克劳德和善逸预览帧统一为 496×444。炭治郎统一为 496×524，并根据审稿图可见脚底对齐；第 3 帧单独绘制后使用最近邻缩放，八帧合成总览为 1984×1048。脚底位置只供查看，并非游戏引擎 anchor，碰撞与真实播放尚未验证。

`build-review.cjs` 仅负责可重复的裁切、填充、近邻缩放、拼图和 manifest 生成；它不绘制人物或背景，也不修改游戏源代码。运行方式：`node build-review.cjs`（需使用环境中已安装的 `sharp`）。
