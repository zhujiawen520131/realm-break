# R4 特效参考与制作简报

日期：2026-11-07（Asia/Shanghai）。范围为六角色各「普攻、技能、必杀」三组，共18组、144张特效生命周期关键帧。`fx-briefs.json` 给出每组的配色、形态、挂点、方向和八阶段说明；这些是新制作方案，不是从原作提取的游戏素材或原作帧表。

本轮保留已通过的角色动作，重做特效。更强的打击感来自清晰的锐核、快速爆发、方向性碎屑、随后及时收敛；不以持续遮住角色的大白光代替冲击。

## 六角色制作方向

- **克劳德**：普攻为有锐前缘的蓝白宽弧，青绿只作内层亮核；技能是随真实弹体飞行的新月剑气；必杀是先后交叉的两道斜刃与短促橙白碰撞火星。当前十字必杀只有一次伤害，视觉反切不私自增加命中次数。
- **劳拉**：普攻采用白热小星核、短黄橙枪焰与迅速退去的灰烟。弓箭只加细银白空气尾迹与小命中尘屑，不变成魔法火球。必杀图集表现一次强化枪焰，按六次实际开枪重触发。
- **天命人**：棍轨是长薄的白金锐线和琥珀外弧，命中飞出切向火星。定身用短促金印、悬浮碎金与细束缚丝；如果图生字不可靠，应由单独文字层绘制准确的「定」。重棍强调下压方向、扁平尘环和地面碎屑，避免看起来像喷火。
- **内森**：拳击仅在真实命中时出现短白冲击线与暖尘，不生成拳气。手雷以实际爆点为中心从白核转为黄橙火瓣，再退成烟和碎屑。步枪压制保留窄长白橙枪焰，按五次实际射击播放，不能变成连续激光。
- **炭治郎**：保留动漫水纹的深蓝描边、分层蓝带和锐白泡沫。水车环必须中央透明并跟随施法者翻滚；水龙由水带和白浪形成，不能改成有肉身鳞片的西方龙。四段命中要保持可数的瞬时亮点。
- **善逸**：青白电芯负责锐度，金色外辉负责爆发。短雷切、横向冲刺雷尾、六连交错轨迹应有明显层级。闪击后迅速断裂成小电枝；轨迹跟随角色操控方向，不凭美术连接敌人或自动瞄准。

## 帧与判定如何对齐

八帧表示一次特效的起亮、扩张、峰值、惯性与消散，不等于八次攻击，也不等于一整招的真实时间。枪手必杀应按每颗真实子弹重启单次枪焰；呼吸技按真实四击/六击产生亮点。飞行剑气的中段可维持，而消散尾帧应在弹体结束时播。

空挥可以出现刀路、空气尾迹或枪口释放，但命中星爆只能在命中事件发生时出现。枪口坐标和方向要沿用R3已校准数据，上挑与空射也不能套水平枪焰。命中停顿、必杀特写会暂停战斗时钟，特效不能继续偷偷走完。制作不改变伤害、能量、连段窗口、自动追踪规则或瞬移操控。

推荐让普通攻击、技能、必杀逐级增加形态复杂度，而非等比例放大一张图。保留角色轮廓、地面参照和敌人位置；低动态/关闭闪光设置继续可用。以上尺寸与节奏约束为本项目设计目标，不是从原作测得的数值。

## 交付与审核

- 每组4列2行、8张独立特效图，真实透明通道；不烘入人物、实体武器、黑底、场景或整块发光矩形。
- 逐帧保持同一原点，留透明隔离边，不能把一张图缩放八次冒充动画。
- 中心留透、亮核锐利、尾部衰减明确；火花、水滴、雷枝有不同的形态，而不是同一种粒子换色。
- 研究用官方图片、预告抽帧仅保留在本地研究目录，不复制成游戏素材。公开报告保留原始来源链接和观察边界。
- 角色动作的既有审批不等于本批新特效自动批准。本批仍需实际游戏合成、时序检查及用户审核。
