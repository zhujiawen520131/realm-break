# 五角色动作帧独立审核（草稿批次 r2）

审核日期：2026-11-07（Asia/Shanghai）。最终结构验证已通过：五角色各13组52帧，合计260帧；30张来源图集SHA全部一致，输出帧无边缘实像素警告。详见 `draft-validation-results.json`。本次交付是供用户审核的独立关键姿态，并非已完成的完整逐帧动画，也尚未替换在线游戏角色动作。用户之前通过的六角色造型与克劳德13组动作审批保持独立。

## 已核对的制作规格

每名角色13组动作、每组4张独立绘制姿态，共52张；五名角色合计65组260张。动作覆盖待机、跑动、跳跃、三段普攻、挑空、空中攻击、受击、防御、冲刺、技能、必杀。四个关键姿态不能代表已补齐动作之间全部中间帧。

真实透明通道、人物朝右、武器完整留在画面内、衣物和装备符合已通过设定、脚底/人体比例稳定、动作有明确准备与发力及恢复，是本批审核重点。图集按2行×4列或3行×4列隔离，每个单元为独立绘图，禁止用同一张图翻转/旋转伪装新姿态。

## 与现有游戏机制对应

`production/preview-timings.json` 提供按角色和动作划分的4帧预览时长（毫秒）。普通攻击时长以目前60Hz引擎招式分段为依据，但仅用于审核播放器，并不宣称游戏已经接入这些帧。跳跃、受击、防御的时间受物理和受击状态控制，预览时长仅帮助观察动作，不是强制游戏时间轴。

## 已发现并修复的制作问题

1. **劳拉技能弓上端裁切。** 原special第2/3帧弓上端越过图集边界，已重生成并目视确认上下端完整。新版双枪有两张不同开火姿态，预览时长同步改为瞄准、交替开火、回收。
2. **天命人长棍影响对齐。** 空中动作与大幅棍击原图为容纳武器缩小人物，已按头部/人体尺寸标定整图缩放，不用武器包围盒高度冒充人体高度；跳跃与冲刺用实际靴底和身体投影定位，避免竖棍末端拖低人物。
3. **天命人必杀轨迹。** 制作代理已将纯砸地意图调整为右前方长棍重击，与现有前方长判定一致。
4. **内森跨图集人物大小。** 待机/跑动与空中稿较小，已补独立倍率标定，保持拳击、射击、受击之间人体尺度更接近。
5. **炭治郎邻行碎片。** 固定等高裁切线穿过上排鞋底，导致冲刺稿上方出现鞋底碎片；在真实透明间隙y466分行，并采用透明间隙自适应裁切以保护刀尖与衣角。
6. **透明性核验。** 使用独立像素统计与灰底Canvas合成确认真实alpha，避免仅凭原图预览器对隐藏RGB的显示判断背景。

## 动作阅读与审核边界

- 劳拉保留持枪近身击、横向拳击与前踢三个不同动作，不把横拳写成已完成的肘击。弓箭与双枪动作明确区别于近战。
- 天命人的水平前击、反向挥棍、上挑与空中落棍方向可区分；长武器的手间距、投影视角与棍长仍需用户逐帧确认。
- 内森拳、肘、前踢、膝击与投掷/步枪姿态分开，受击与主动防御姿态可读。
- 炭治郎保留格纹羽织、耳饰与黑色日轮刀；水车补入明确的头下脚上旋转关键姿态，水龙必杀使用不同方向的代表斩击。
- 善逸保留橙金发、三角羽织与刀鞘；技能低身拔刀、必杀更长幅度的低身突进可区分。跑动已改用四张步态区别更清楚的新版姿态并复核。已对最终归一化总览检查，并对新空中和特殊动作补1.2倍人体尺度标定。
- 待机变化较轻；四帧跑动只有接触/收腿的关键节拍，尚未补齐中间帧。用户可重点检查左右腿交替、武器握持、回收是否自然。静态审核不能等同于已经通过真实战斗手感验收。

## 最终视觉复核

已逐角色查看五张52帧总览，并对关键武器与可疑裁切点查看原尺寸画面。劳拉新弓箭/双枪稿与善逸新空中/特殊稿补充1.2倍整图标定，克服为保留武器而缩小人体的跨图集差异。以上只改变图集拆分后的统一缩放和定位，没有生成假动作。

自动边缘提醒中的四项（炭治郎普攻二段第3帧、空中斩第3帧；善逸冲刺第3帧、普攻二段第3帧）已在原尺寸灰底合成图中核对，刀尖、靴底与衣角均完整，无邻格人物碎片。这些提醒来自图形距离安全透明间隙较近，并非已确认的截断。

水车第2/3帧在审核播放器内分别使用-60/-90像素的空翻预览偏移，避免倒置头部贴地；这不表示引擎已经加入腾空判定。未来接入水车需保留合适的动画局部位移/旋转支点，不可直接机械删除偏移后让头部落地。

本次没有把上述关键姿态称为已完成的平滑动画循环；跑步中间相位、连招连续性和多次射击/多段斩击的实际播放仍需后续游戏接入时验证。审核播放器提供慢放和逐帧检查，用户可针对帧号继续反馈。
