# 裂界 R3 动作研究与制作依据

本轮交付六名角色、每人普攻三段／技能／必杀，共30条动作、240个关键姿势。父代理另外负责的2条劳拉辅助动作独立计数，不包含在本研究30条内。`motion-briefs.json` 是机器可读总表，`<hero>-brief.json` 可独立交给制作代理。每条动作包含8个身体姿态、武器端点方位、中文阶段标签、建议时长、独立特效提示和完整英文制作提示。**这些是为本作重新编排的2D格斗动作，不是原作逐帧复制，也不是已完成的实机动画。**

## 给制作的核心约束

1. 斩击是刃口扫弧：武器朝向至少三次显著改变，身体至少出现两种不同前后侧面。脚先蹬、髋先转、肩随后、手腕和刀尖滞后，命中后必须有随动与制动。不能把同一个侧身复制8次并向前伸胳膊。
2. 横斩需表现近远透视和剑身缩短；斜上、斜下、横扫各有独立切割平面。FX关闭后仍须看得出刀经过目标，而不是仅让直线光束代表出刀。
3. 枪械使用稳定瞄准、短促后坐、回正；它不需要像大剑一样夸张转体。劳拉三段普攻分别右枪点射、左枪接射、终结点射，第三段仍双手持枪但只由一把枪释放一发终结子弹，均为射击，不夹杂拳脚或用枪柄敲击。
4. 居合先握鞘、拔刀、刀身脱鞘、刃口扫过，再制动／回鞘；左手一直明确持鞘，不能多一把刀或一帧自动回鞘。善逸疾行方向采用玩家输入，不在素材里追踪敌人。
5. 天命人棍法横扫、反扫、重劈有明确握距和两手控制；原作确实存在戳棍，不能说所有刺击都错，本轮只修正本应挥扫却被画成前戳的动作。
6. 特效仅在相应身体动作之后出现：刀弧附刃、枪火出枪口、箭出弓弦、手雷离手。技能海报位于动作前的独立演出层，不遮掉出手和命中。

## 30条动作方案

|角色|普攻一／二／三|技能|必杀|
|---|---|---|---|
|克劳德|巨剑斜下斩／反向腰平横斩／过顶重劈|上挥刃缘释放破晄击波|站地两次交叉切割；首刀后重新转髋再逆向第二刀|
|劳拉|右枪点射／左枪接射／终结点射（持双枪，仅一枪一发）|左臂撑弓、右肩胛拉弦、松指后手随动|双枪机动连射，身体关键姿势与运行时6发子弹分开|
|天命人|转髋横扫／反向腰扫／双手过顶重劈|持棍支撑＋单手定身手诀|绕身蓄力后向前下方重击，保持原型正面攻击范围|
|内森|短直拳／髋肩驱动勾拳／跨步短肘|髋肩肘顺序带动过顶手雷投掷|托肩步枪点连射，微幅后坐回正，5发子弹由运行时调度|
|炭治郎|水面横斩／逆袈裟上斩／斜下重斩|水之呼吸·水车：蹲身蓄力、起跳、团身、前翻、倒置挥斩、随转、落地、回收（8姿势改编）|先下后上双斩带出水龙，身体先行水龙随后|
|善逸|居合拔刀／已出鞘反斩／过顶下斩|深蹲压腿后拔刀疾行，刃口横扫而非枪矛冲刺|两次可见切割＋运行时六次打击／残影；8姿势不能冒称完整六刀逐帧|

每个8姿势方案独立写明预备、发力、命中和回收。地面斩击采用蹬地转髋、转肩加速与随动制动；炭治郎水车则采用蹲身蓄力、起跳、团身、前翻、倒置挥斩、旋转随动、屈膝落地、回收，不改成站立释放月牙。`durationsMs`只是制作建议；若游戏采用固定动作总时长，须归一化权重，不能随意改变命中发生时刻。`suggestedProjectedWeaponAngleDeg`是草图的投影方向建议，0°向右、90°向上；不是原作测量数据，横扫仍需加入景深与透视。

## 验收与接招

- 先关FX看动画：出手前后脚、骨盆、肩线、刀尖都应有可辨别变化，不能靠镜头震动掩盖静止身体。
- 以接触帧驱动命中判定、音效与短顿帧；后坐/刀随动不能在命中判定前结束。
- 连击取消窗应落在已命中的随动阶段，接下一段时优先从前一段末尾持械方位开始；不能刀从左侧瞬间跳回右侧。
- 远程投射物释放后独立飞行；玩家移动不能拖着已经射出的子弹／箭／手雷走。
- 本研究并不表示素材已通过视觉验收：每条新序列仍需检查8格是否真是连续不同姿势、武器与手部是否连续、腿脚有无漂移、是否满足用户审核。
