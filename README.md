# 界域 · REALM BREAK

二次元像素横版格斗可玩原型 V0.1。原创主角马楠以场景构筑能力作战，天命人与克劳德作为客串角色，各有六种技能。

## 直接游玩

**https://zhujiawen520131.github.io/realm-break/**

打开页面即可游玩，无需安装。推荐使用桌面 Chrome 或 Edge。也可以下载仓库根目录的 `index.html`，在浏览器中离线打开；图片与音效逻辑全部内嵌，不依赖外部资源。

## 已包含

- 三名可选角色：马楠、天命人、克劳德。
- 五张场景：水晶都市、山中古寺、雨夜古巷、北境冰原、雨林古墓。
- 人机对战（三级难度）、本地双人、自由训练。
- 三局两胜、99 秒计时、能量、技能冷却、防御、弹反、闪避、爆气与受击保护。
- 马楠技能：地形雕刻、模组拼接、材质覆写、植被散布、灯光聚焦、关卡重构。

## 操作

| 动作 | P1 | P2（本地双人） |
| --- | --- | --- |
| 移动、跳跃、蹲下 | A D / W / S | ← → / ↑ / ↓ |
| 拳、脚、特殊技 | J / K / L | 小键盘 1 / 2 / 3 |
| 闪避、防御、爆气 | U / 按住 I / O | 小键盘 4 / 按住 5 / 6 |
| 六种角色技能 | Q E R F G H，也可点击技能按钮 | 3 / 7 / 8 / 9 / . / 0 |
| 暂停 | Esc | Esc |

也支持方向组合出招，具体见游戏内“操作指南”。移动设备提供屏幕按键。标准手柄映射已接入（未做实体手柄验证）：左摇杆移动，A 跳、X 拳、B 脚、Y 特殊技、LB 防御、RB 闪避、RT 爆气；按住 LT 后，X / Y / B / A / LB / RB 对应六种技能。

## 验证与范围

完成 23 项本地逻辑检查，并在浏览器中验证选人、换场景、训练技能、人机对战和暂停。V0.1 为玩法原型，动作采用关键姿态与程序过渡；未包含联网对战或剧情模式。场景与角色技能数值还可以继续打磨。
