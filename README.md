## V0.5 重做

依据《死神 vs 火影 3.3》必杀演出的短切入、快速位移连打和大轮廓终结重新设计动作节奏。

- 战场人物统一144px，碰撞间距、近战与处决起手距离同步调整。
- 新增24张瞬步、突进、上挑、空中攻击、俯冲和落地绘图，合计210张。
- J轻击连段后K上挑，命中后W可跳追；U可取消已命中的普攻，空挥需正常收招。
- Q入身上挑、E短位移、R重动作及F/G恢复窗口；保留场景构筑、棍术和剑术主题。
- 0.30秒大必杀肖像切入，三角色真实换位、升空连打与落地：马楠模组夹击后短促碎景重构、天命人棍轮分身到巨棍终结、克劳德交错斩。
- 大必杀时间轴含切入为2.95/2.70/2.50秒，另含命中停顿；起手距离有限，格挡/闪避/落空不进入处决。
- 保留真实倒地与起身、死亡躺地和KO停留、街机选人、三人接力和训练。
