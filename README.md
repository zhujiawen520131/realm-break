## 操作

| 动作 | P1 | P2（本地双人） |
| --- | --- | --- |
| 移动 / 二段跳 / 蹲防 | AD / 空格 / S | ←→ / ↑ / ↓ |
| 轻击 / 重击 / 挑空 | J / K / L | 小键盘1 / 2 / 3 |
| 翻滚 / 爆气 | C / V | 小键盘4 / 6 |
| 技能1 / 技能2 | U / I | 小键盘− / 7 |
| 小必杀 / 大必杀 | O / P | 小键盘+ / 0 |
| 辅助技能 | R / F / G | 小键盘8 / 9 / . |
| 暂停 | Esc | Esc |

J→J→L后跳起追击；L也可独立挑空。W兼容跳跃，Q/E兼容U/I，T/H兼容O/P。训练能量无限，靠近目标按O/P；大招空挥或被防住不会进入演出。选人WASD/J确认/K撤销，P2方向键/小键盘1确认/2撤销。

标准手柄：A跳跃，X/B/Y轻击/重击/挑空，LB翻滚，RB/RT技能1/2，Back爆气；按住LT时RB/RT为大/小必杀。实体手柄未实测，映射经过模拟检查。

60项检查通过，包含原有键位、二段跳、翻滚与KO回归，新增15分身事件一致性、两角色低血量末击与完整尾声锁定、实际动作帧和落地速度检查。浏览器实测两套P键必杀和技能栏。
