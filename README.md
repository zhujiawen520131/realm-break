# 界域 · REALM BREAK

二次元像素横版格斗可玩原型 V0.2。原创主角马楠以场景构筑能力作战，天命人与克劳德作为客串角色，各有六种技能。

## 直接游玩

**https://zhujiawen520131.github.io/realm-break/?v=0.2**

打开页面即可游玩，无需安装。推荐桌面 Chrome 或 Edge。右上角版本显示 0.2。也可以下载根目录 `index.html`，在浏览器中离线打开；全部图片和音效逻辑已内嵌。

## V0.2 动作与打击反馈更新

- 每名角色 48 张基础动作绘图与 8 张专属必杀绘图，共 168 张动作素材。
- 待机、跑动、普攻、踢腿和施法各使用八帧序列；另含四帧跳跃、四帧受击。
- 增加起手、接触、跟随动作和收招，统一身体定位与脚底基线；通过完整连通轮廓提取，保留跨越图集格子的拳头、棍与剑。
- 加强轻重攻击命中停顿、受击闪白、冲击碎片、镜头反馈和分层打击音效。声音默认开启，可在右上角关闭。
- 三种专属必杀均包含特写、独立序列和实际伤害判定：马楠“关卡重构”、天命人“擎天一棍”、克劳德“极限交叉斩”。
- 校准克劳德必杀突进的实际位置，限制特写期间跳跃与施法者爆气打断，保证演出与判定一致。

## 游戏内容

三名角色、五张场景（水晶都市、山中古寺、雨夜古巷、北境冰原、雨林古墓）；人机三级难度、本地双人、自由训练；三局两胜、99 秒计时、能量、冷却、防御、弹反、闪避、爆气及受击保护。

马楠技能：地形雕刻、模组拼接、材质覆写、植被散布、灯光聚焦、关卡重构。

## 操作

| 动作 | P1 | P2（本地双人） |
| --- | --- | --- |
| 移动、跳跃、蹲下 | A D / W / S | ← → / ↑ / ↓ |
| 拳、脚、特殊技 | J / K / L | 小键盘 1 / 2 / 3 |
| 闪避、防御、爆气 | U / 按住 I / O | 小键盘 4 / 按住 5 / 6 |
| 六种角色技能 | Q E R F G H，也可点击技能按钮 | 3 / 7 / 8 / 9 / . / 0 |
| 暂停 | Esc | Esc |

训练模式能量无限，可直接按 H 体验必杀；普通对战需积满 100 能量。

也支持方向组合出招，详见游戏内“操作指南”。移动设备提供屏幕按键。标准手柄映射已接入（未做实体手柄验证）：左摇杆移动，A 跳、X 拳、B 脚、Y 特殊技、LB 防御、RB 闪避、RT 爆气；按住 LT 后，X / Y / B / A / LB / RB 对应六种技能。
