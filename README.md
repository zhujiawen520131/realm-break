# 界域 · REALM BREAK

二次元像素横版格斗可玩原型 V0.3。马楠以场景构筑能力作战，天命人、克劳德各有专属技能。

## 直接游玩

**https://zhujiawen520131.github.io/realm-break/?v=0.3**

推荐桌面 Chrome / Edge；右上角版本显示 0.3。全部资源内嵌，也可下载 index.html 离线打开。

## V0.3 更新

- 街机式中央头像阵列、两侧大肖像、P1/P2 独立光标、确认和撤销、随机角色、三人队伍栏。
- 3 VS 3 接力按选择顺序实际上场；胜者保留生命并恢复 80，败者换人。也可选择三局两胜 1 VS 1。
- 修复命中镜头错误重新居中和随机位移；保留固定中心的小幅命中缩放。
- 按住 S / ↓ 自动蹲防正面攻击；站立防御和及时弹反仍保留。
- 移动约加快 20%，缩短拳脚起手及收招，命中后可取消普攻接技能。
- 新增 50 能量小必杀：马楠“蓝图岩阵”、天命人“棍花龙卷”、克劳德“蓝焰三连斩”。0.35 秒短切入，攻击有距离限制，可防御和闪避。
- 100 能量大必杀保留完整专属过场：马楠将当前场景瓦解为 96 个碎片并重构；天命人召出带金饰纹样的巨型如意金箍棒；克劳德突进交叉连斩。
- 三角色共 168 张动作绘图：每角色 48 张基础动作、8 张必杀绘图。分层命中粒子、受击闪白、停顿及合成打击音效。

## 内容与操作

三角色、五场景；三级人机、本地双人、自由训练；能量、冷却、防御槽、弹反、闪避、爆气和受击保护。无联网对战或剧情模式。

| 动作 | P1 | P2（本地双人） |
| --- | --- | --- |
| 选人移动 / 确认 / 撤销 | WASD / J / K | 方向键 / 小键盘 1 / 2 |
| 战斗移动 / 跳跃 / 蹲防 | AD / W / S | ←→ / ↑ / ↓ |
| 拳 / 脚 / 特殊技 | J / K / L | 小键盘 1 / 2 / 3 |
| 闪避 / 站立防御 / 爆气 | U / 按住 I / O | 小键盘 4 / 按住 5 / 6 |
| 小必杀 / 大必杀 | T / H | 小键盘 + / 0 |
| 六种技能 | Q E R F G H 或点击按钮 | 小键盘 3 / 7 / 8 / 9 / . / 0 |
| 暂停 | Esc | Esc |

↓→L 为小必杀，↓←L 为大必杀；方向随面朝方向变化。训练能量无限，可直接 T / H 体验。移动端有屏幕按键；手柄详见游戏内指南（未进行实体手柄验证）。
