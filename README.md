## V0.4 更新

- 移动速度提升至 430 / 450 / 400，移动时朝向行进方向；拳脚节奏加快。
- 新增18张专用受击、倒地、躺地和起身绘图，合计186张动作绘图。
- 击飞后依次落地、倒地、起身，死亡保持躺地；KO与胜利姿势至少保留3秒。
- 三角色大必杀先进行真实距离命中判定，落空、闪避或蹲防不会进入处决。
- 马楠碎景重构夹击、天命人连棍挑空与巨棍终结、克劳德交错高速斩；双方参与移动受击，分段扣血，终结后衔接倒地或死亡。
- 保留街机选人、三人接力、蹲防、50气小必杀、三级人机和训练。
