## V0.6 更新

- 新键位：J/K/L轻击、重击、挑空；U/I角色技能；O/P小必杀、大必杀；C翻滚；空格二段跳；S蹲防；V爆气。
- C使用真实低身翻滚绘图，持续0.36秒，前0.18秒无敌，1.1秒冷却；可穿过近身对手，空中或死亡不能翻滚。
- 空格起跳后松开再按可二段跳，最多两次，落地重置；长按不会无限跳。
- 新增24张翻滚/二跳绘图、36张必杀绘图，共270张动作绘图；三角色大必杀实际逐张使用12帧。
- 必杀升空改为单次抛物线，真实位置与速度方向一致，落地后保持接地，结束清零速度；动作与武器保持固定身体比例。
- 技能栏按U I O P排列，R/F/G辅助技能保留，指南、移动按键和手柄提示已同步。
- 保留真实倒地起身、死亡躺地、KO停留、街机三人选队、接力、双人和训练。

## 操作

| 动作 | P1 | P2（本地双人） |
| --- | --- | --- |
| 移动 / 二段跳 / 蹲防 | AD / 空格 / S | ←→ / ↑ / ↓ |
| 轻击 / 重击 / 挑空 | J / K / L | 小键盘1 / 2 / 3 |
| 翻滚 / 爆气 | C / V | 小键盘4 / 6 |
| 技能1 / 技能2 | U / I | 小键盘− / 7 |
| 小必杀 / 大必杀 | O / P | 小键盘+ / 0 |
| 辅助技能 | R / F / G | 小键盘8 / 9 / . |
| 暂停 | Esc | Esc |

J→J→L后跳起追击；L也可独立挑空。W兼容跳跃，Q/E兼容U/I，T/H兼容O/P。训练能量无限，靠近目标按O/P；大招空挥或被防住不会进入演出。选人WASD/J确认/K撤销，P2方向键/小键盘1确认/2撤销。

标准手柄：A跳跃，X/B/Y轻击/重击/挑空，LB翻滚，RB/RT技能1/2，Back爆气；按住LT时RB/RT为大/小必杀。实体手柄未实测，映射经过模拟检查。
